- 2026-11-18: Security review fixes SEC-5-1 (MEDIUM) and SEC-5-8 (LOW; ISS-027, ISS-028) in forward migration `20261117103000_throttle_hardening` (applied to dev as `throttle_hardening`). Throttle key: IPv6 sources collapse to their /64 prefix, IPv4 unchanged, IPv4-mapped IPv6 keyed as the IPv4 address, anything unparseable falls back to the raw text (never raises); still salted SHA-256, helper still not callable by API roles. New index on `public_link_attempts (window_start)`. Cleanup on every failure call deletes at most 50 rows older than 1 day via that index, inside an exception block so it cannot fail the failure record. Once the global breaker is open (1000 failures per window), a failure only increments the global row and rows that already exist; no new per-source rows. Behaviour note: while the breaker is open a source that had not failed earlier in the window is no longer held back after its first failure (no row exists for it); sources that already failed are still held back. `submit_public_decision` rejects a raw comment longer than 8000 characters (result `validation`) before the trim regex. Developer pgTAP 115/115 (24 added; one breaker assertion reworded to the new behaviour). Tester suites 157/157, change orders 39/39 and 125/125. Advisors: only documented dispositions.
